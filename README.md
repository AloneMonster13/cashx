# CashX → Acumatica

Static site. No build step, no server; files are processed in the browser only.

## Deploy on Vercel (free)
1. Put these 3 files in a folder: `index.html`, `engine.js`, `vercel.json`.
2. Either drag the folder onto https://vercel.com/new  or run `npx vercel --prod` inside it.

## Use
Open the site → drop the CashX export → download the AR and AP files.
Customer IDs / vendor IDs you type are remembered in that browser.
